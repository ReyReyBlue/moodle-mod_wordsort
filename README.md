# Word Sort

Moodle'i tegevusmoodul, mis kutsub õpilasi üles kiiresti ülesandeid ühte kahest õpetaja määratud kategooriast liigitama.

## Funktsioonid

- Kaks konfigureeritavat kategooriat
- Ajastatud mäng
- Mitu katset
- Valikuline "shuffle"
- Kohene tagasiside
- Õpetaja aruanded
- Moodle'i hinneteraamatu integratsioon

## Staatus

Aktiivses arenduses

## Nõuded

- Moodle 4.5+
- PHP 8.2+
- MariaDB
