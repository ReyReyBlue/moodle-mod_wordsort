# Word Sort
## Project Overview

Word Sort is a custom Moodle Activity Module developed during a summer internship.

The activity is designed to improve learning through fast categorization tasks. Students are presented with a word or phrase and must quickly assign it to one of two teacher-defined categories before the timer expires.

The plugin is intended for educational use in higher education but can also be used in schools or corporate training.

---

## Main Features

- Two configurable categories
- Teacher-defined words or phrases
- Teacher can import and export words with categories between wordsort activites
- Configurable timer
- Multiple attempts
- Optional random order
- Immediate feedback (optional)
- Teacher reports
- Moodle Gradebook integration
- English and Estonian language support
